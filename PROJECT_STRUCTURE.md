# 📁 Структура проекта Tarot Bot для VK Max

Этот документ описывает полную структуру проекта и назначение каждого файла.

## 🌲 Общая структура

```
tarot-bot-vkmax/
├── backend/                  # Backend (Python + FastAPI)
│   ├── __init__.py          # Инициализация пакета
│   ├── main.py              # Главный файл приложения FastAPI
│   ├── config.py            # Конфигурация приложения
│   ├── database.py          # Настройка и подключение к БД
│   ├── models.py            # Модели базы данных (SQLAlchemy)
│   ├── schemas.py           # Pydantic схемы для валидации
│   ├── auth.py              # Авторизация и аутентификация
│   ├── tarot.py             # Логика работы с картами Таро
│   ├── payment.py            # Обработка платежей и подписок
│   ├── requirements.txt      # Python зависимости
│   └── .env.example          # Пример файла конфигурации
│
├── frontend/                # Frontend (HTML/CSS/JS)
│   ├── index.html           # Главная HTML страница
│   ├── styles.css           # Стили приложения
│   ├── auth.js              # Авторизация и интеграция с VK
│   ├── spreads.js           # Логика работы с раскладами
│   ├── app.js               # Основная логика приложения
│   └── __init__.py          # Инициализация пакета
│
├── data/                   # Данные
│   ├── tarot_deck.json      # База данных карт Таро (78 карт)
│   └── spreads.json         # Описания раскладов

│
├── .gitignore              # Игнорируемые файлы для Git

├── DEPLOYMENT.md           # Инструкции по развертыванию
```

## 🏗 Backend (Python + FastAPI)

### `backend/main.py`
**Назначение:** Главный файл приложения FastAPI

**Содержимое:**
- Настройка FastAPI приложения
- CORS middleware
- API эндпоинты:
  - `/api/` - корневой эндпоинт
  - `/api/auth/vk` - авторизация через VK
  - `/api/user` - информация о пользователе
  - `/api/user/subscription` - статус подписки
  - `/api/tarot/decks` - список колод
  - `/api/tarot/cards` - список карт
  - `/api/tarot/spreads/free` - бесплатные расклады
  - `/api/tarot/spreads/premium` - premium расклады
  - `/api/tarot/spread` - создание расклада
  - `/api/tarot/spreads/history` - история раскладов
  - `/api/user/preferences` - настройки пользователя
  - `/api/payment/subscribe` - оформление подписки
  - `/api/payment/cancel` - отмена подписки
  - `/api/health` - проверка здоровья

**Технологии:** FastAPI, Pydantic, SQLAlchemy

---

### `backend/config.py`
**Назначение:** Конфигурация приложения

**Содержимое:**
- Настройки VK Mini App (ID, Secret, Token)
- Настройки базы данных (URL)
- Настройки сервера (Host, Port, Debug)
- Настройки безопасности (Secret Key, Algorithm)
- Настройки подписки (цена, длительность)
- Ограничения (лимит бесплатных раскладов)
- Настройки по умолчанию (колода, перевернутые карты)

**Технологии:** Pydantic Settings

---

### `backend/database.py`
**Назначение:** Подключение и настройка базы данных

**Содержимое:**
- Создание SQLAlchemy engine
- Создание session factory
- Функции для получения сессии
- Инициализация базы данных
- Очистка базы данных

**Технологии:** SQLAlchemy, SQLite/PostgreSQL

---

### `backend/models.py`
**Назначение:** Модели базы данных

**Содержимое:**
- **User** - модель пользователя
  - vk_id, first_name, last_name, photo
  - is_premium, subscription_start, subscription_end
  - last_free_spread_date, free_spreads_count
  - preferred_deck, allow_reversed_cards
  - created_at, updated_at
  
- **Spread** - модель расклада
  - user_id, spread_type, question
  - cards (JSON), interpretation, advice
  - deck_used, allow_reversed
  - created_at
  
- **Payment** - модель платежа
  - user_id, payment_system, payment_id
  - amount, currency
  - subscription_duration
  - status, created_at, completed_at
  
- **TarotDeck** - модель колоды Таро
  - deck_id, name_ru, name_en, description
  - author, year, is_active, image_prefix
  
- **Card** - модель карты Таро
  - card_id, deck_id
  - name_ru, name_en, card_type
  - suit, number, element
  - meaning_up_short/full, meaning_down_short/full
  - keywords_up/down, advice, image_path

**Технологии:** SQLAlchemy ORM

---

### `backend/schemas.py`
**Назначение:** Pydantic схемы для валидации данных

**Содержимое:**
- **Token** - схема JWT токена
- **TokenData** - данные токена
- **UserBase**, **UserCreate**, **User**, **UserInDB** - схемы пользователя
- **Card** - схема карты
- **Position** - схема позиции в раскладе
- **SpreadResult** - схема результата расклада
- **SpreadRequest** - схема запроса на расклад
- **PaymentCreate**, **PaymentResponse** - схемы платежа
- **SubscriptionStatus** - статус подписки
- **SpreadInfo** - информация о раскладе
- **DeckInfo** - информация о колоде
- **UserPreferences** - настройки пользователя
- **ErrorResponse**, **MessageResponse** - схемы ответов

**Технологии:** Pydantic

---

### `backend/auth.py`
**Назначение:** Авторизация и аутентификация

**Содержимое:**
- Функции для работы с JWT токенами
- Авторизация через VK Mini App
- Получение информации о пользователе из VK
- Создание и проверка JWT токенов
- Middleware для проверки аутентификации

**Технологии:** JWT, OAuth2, VK API

---

### `backend/tarot.py`
**Назначение:** Логика работы с картами Таро

**Содержимое:**
- **TarotManager** - класс для управления картами и раскладами
  - Загрузка данных из JSON файлов
  - Получение колод, карт, раскладов
  - Выбор случайных карт
  - Выполнение раскладов
  - Генерация интерпретаций
  - Генерация советов
  - Анализ раскладов (типы карт, масти, элементы)

**Технологии:** Python, JSON

---

### `backend/payment.py`
**Назначение:** Обработка платежей и подписок

**Содержимое:**
- Обработка платежей через различные системы
- Активация и отмена подписок
- Интеграция с YooMoney
- Интеграция с Сбербанк Онлайн
- Проверка статуса подписки

**Технологии:** HTTPX, VK Pay API, YooMoney API

## 📊 Data (Данные)

### `data/tarot_deck.json`
**Назначение:** База данных карт Таро

**Содержимое:**
- Информация о колоде (название, описание, автор)
- **78 карт Таро:**
  - **22 Старших Арканов** (0-21):
    - Шут, Маг, Верховная Жрица, Императрица, Император, Иерофант, Влюбленные, Колесница, Сила, Отшельник, Колесо Фортуны, Справедливость, Повешенный, Смерть, Умеренность, Дьявол, Башня, Звезда, Луна, Солнце, Суд, Мир
  - **56 Младших Арканов:**
    - **Жезлы (Огонь)** - 14 карт: Туз, 2-10, Валет, Рыцарь, Королева, Король
    - **Кубки (Вода)** - 14 карт
    - **Мечи (Воздух)** - 14 карт
    - **Пенткли (Земля)** - 14 карт
  
- Для каждой карты:
  - ID, имя на русском и английском
  - Тип (major/minor), масть, номер
  - Элемент (Огонь, Вода, Воздух, Земля)
  - Изображение
  - Значения в прямом и перевернутом положении (короткое и полное)
  - Ключевые слова
  - Совет

  - **Кельтский крест** (celtic_cross) - 10 позиций
  - **Дерево жизни** (tree_of_life) - 11 позиций (Каббала)
  - **Астрологический** (astrological) - 12 позиций (по знакам зодиака)
  - **Расклад на год** (year_ahead) - 12 позиций (по месяцам)
  
- Для каждого расклада:
  - ID, название, описание
  - Категория (free/premium)
  - Сложность, время выполнения
  - Позиции с описаниями
  - Шаблоны интерпретации
  - Вопросы для расклада
